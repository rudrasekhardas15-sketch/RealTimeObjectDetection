# Real-Time Object Detection

A real-time object detection web application that uses your webcam to detect objects using TensorFlow.js and the COCO-SSD model.

## 🚀 Features

- Real-time webcam object detection
- Bounding boxes around detected objects
- Object names and confidence percentages
- Object count
- FPS counter
- Start / Stop camera controls
- Adjustable confidence threshold
- Responsive design
- Runs directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- TensorFlow.js
- COCO-SSD
- WebRTC Camera API

## 📸 How It Works

1. The browser requests webcam access.
2. TensorFlow.js loads the COCO-SSD object detection model.
3. The webcam video is continuously analyzed.
4. Detected objects are displayed with bounding boxes.
5. The application shows the object name and confidence score.
